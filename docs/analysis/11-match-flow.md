# TFT — Match Flow Framework (Round-by-Round)

> Checklist mỗi round. Engine map state → action theo bảng này.

---

## Stage 1 (1-1 → 1-3)

| Round | Action |
|-------|--------|
| 1-1 | Buy bất kỳ unit nào fit nhiều comp. **Luôn mua ≥2 unit ở 1-1.** |
| 1-2 / 1-3 | Build strongest board, max 2★. Board strength = HP preservation. |
| 1-4 | **Carousel đầu tiên** — grab component tốt nhất (B.F. / Rod / Belt), bỏ qua champ trừ khi là 2★ đang progress mạnh |

**Beginner mistake**: skip shop ở 1-1 đợi "unit hoàn hảo". Mua ít nhất 2 unit.

---

## Stage 2 (2-1 → 2-7)

| Round | Action |
|-------|--------|
| **2-1** | Lv4 (free). **Silver augment choice.** Pick direction here. |
| 2-2 / 2-3 | Play strongest. Decide: win streak nếu 2★ ra nhiều; loss streak nếu board yếu |
| 2-5 | Lv5 để max carousel drops ở 2-7. Hold BIS components nếu đã biết comp |
| 2-7 | **Krugs**. Collect items. Nếu board yếu, intentional loss cho streak |

**Beginner mistake**: force comp theo augment mà không flex; chase BIS items trong khi HP leak.

---

## Stage 3 (3-1 → 3-7)

| Round | Action |
|-------|--------|
| 3-1 | Lv6 natural tới |
| **3-2** | **Gold augment** + lv6. Econ check: ≥30g thì tiếp tục hoard |
| 3-3 / 3-5 | Slow-roll @ 6 nếu 1c reroll; otherwise push lv7 ở 3-5 |
| 3-7 | **Wolves**. Last PvE trước stage 4 power spike |

**Beginner mistake**: roll ở lv6 mà không có reroll comp; chase 3★ 1-cost mình không cần.

---

## Stage 4 (4-1 → 4-7)

| Round | Action |
|-------|--------|
| **4-1** | **Fast 8 window**. HP ≥60, gold ≥50 → lên 8 roll ngay |
| **4-2** | **Prismatic augment** + standard lv8 + rolldown |
| 4-3 | Stabilize nếu rolldown xong; roll thêm nếu chưa |
| 4-5 | Last chance roll về 20g trước stage 5 |
| 4-7 | **Raptors**. Nếu stabilized, items vào carry |

**Beginner mistake**: không lên 8 trước 4-5; roll 4-cost ở lv7.

---

## Stage 5 (5-1 → 5-7)

| Round | Action |
|-------|--------|
| **5-1** | Lv9 nếu HP ≥50 và gold ≥50. Otherwise econ ở 8 |
| 5-2 → 5-5 | Hit 5-cost, finalize comp cap |
| 5-7 | **PvE drops**. Prepare stage 6 |

**Beginner mistake**: dump gold ở 8 chase 4★ (impossible); không push 9 khi top-4 đã secure.

---

## Stage 6+ (6-1 → end)

| Round | Action |
|-------|--------|
| 6-x | Lv10 nếu dẫn; roll 2★ 5-costs. Final positioning |
| 7-x | Chỉ top 2 tới đây. Mirror-hex, counter-position, grief |

**Beginner mistake**: không scout final opponent; không pivot backline chống assassin threat đã biết.

---

## Rule chung mỗi round

1. **Buy** mọi unit đã 2★-progress trên board
2. **Compare** board strength vs lobby average (scoreboard)
3. **Scout** next opponent trong 10s cuối planning
4. **Position** cuối — carry placement là quyết định 5s cuối

---

## Critical decision rounds

| Round | Decision |
|-------|----------|
| **2-1** | Silver augment (set opener line) |
| **2-5** | Hold hoặc slam first items |
| **3-2** | Gold augment + lv6 + commit comp |
| **3-5** | Push 7 hoặc hold econ |
| **4-1** | Fast 8 hoặc standard? |
| **4-2** | Prismatic augment + rolldown trigger |
| **5-1** | Lv9 hoặc stabilize 8? |
| **5-5** | Final cap push vs grief cho placement |

---

## Opener → Mid → Late pattern (standard tempo)

```
Stage 1    : collect items, build strongest board
2-1        : Silver augment; keep streak nếu có thể
2-5 → 3-1  : lv5–6 natural; econ to 30+
3-2        : Gold augment; lv6; econ to 50g
3-5 → 4-1  : lv7; vẫn 50g+; evaluate comp commitment
4-2        : Prismatic augment; lv8; roll ~30g for carry
4-5 → 5-1  : stabilize; slam items; lv9 nếu HP ≥50
5-x        : push 9; roll 5-cost cap; finalize positioning
6-x+       : lv10 nếu ahead; grief hoặc play cho top-1
```

## Example line — Solar Kayle Reroll

- **Opener stage 2**: Slow econ, hold components (ưu tiên BF/Rod)
- **3-2 (lv6)**: Slow-roll trên 50g tìm Kayle, Ornn, Leona 3★
- **Bench priority**: Kayle 3★ > Ornn 3★ > Xayah/Leona > Sejuani > Rakan
- **Lv7 ở 4-5 hoặc muộn hơn**: cho cap
- **Final board (7–8 units)**: Kayle(3), Ornn(3), Leona, Sejuani, Rakan, Xayah, LeBlanc
- **Items**: Kayle = Rageblade + JG + Hextech Gunblade; Ornn = Gargoyle Stoneplate
- **Augment synergy**: Cursed Crown (8 units ở lv6)

## Example line — Executioner Azir

- **Opener**: Hold components, aim BF/Rod/Belt
- **Stage 3**: Lv6 ở 3-2, econ to 50g, play strongest board
- **4-1/4-2**: Lv8, roll ~30g về ~15–20g tìm Azir 2★
- **BIS**: Spear of Shojin + Rageblade + Jeweled Gauntlet (hoặc Giant Slayer)
- **Nếu reroll variant @ lv7**: slow-roll từ 4-1 cho Azir / Kha'Zix / Vi 3★s, keep ≥50g

## Opponent reading cheatsheet

| Observation | Likely meaning |
|-------------|----------------|
| HP cao (80+) + gold cao (50+) ở stage 3 | Econ player, Fast 8 incoming |
| HP thấp (30–50) + gold hoard | Risky Fast 8/9, có thể stabilize hoặc chết |
| HP <30 + gold thấp | Reroll player committed, sắp chết |
| HP 90+ + gold <20 | Over-leveled / tiêu XP, sắp roll |
| HP 50–70 + 50g | Textbook interest cap, standard tempo |

## State machine (engine)

```python
class MatchPhase(Enum):
    OPENER = "stage_1_2"           # vòng 1-x đến 2-x
    MIDGAME = "stage_3_4"          # 3-x đến 4-x
    LATEGAME = "stage_5_plus"      # 5-x trở đi

def current_phase(state: GameState) -> MatchPhase:
    if state.stage <= 2: return MatchPhase.OPENER
    if state.stage <= 4: return MatchPhase.MIDGAME
    return MatchPhase.LATEGAME

ROUND_PRIORITIES = {
    "2-1": ["pick_augment"],
    "3-2": ["pick_augment", "evaluate_level_up"],
    "4-1": ["evaluate_fast_8"],
    "4-2": ["pick_augment", "level_8", "rolldown"],
    "5-1": ["evaluate_fast_9"],
    # ...
}
```
